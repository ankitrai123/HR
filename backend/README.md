# Hybrid Psychometric Assessment Backend

Scores the 175-item personality inventory on 11 competency dimensions and produces reports in two tiers:

- **Standard reports** are deterministic, need no network access, and take under 1 ms. They include Sten scores, percentiles, levels, 33 pre-written interpretations, strengths and development areas, and response-quality checks.
- **Premium reports** add an executive summary, a development plan, coaching insights and richer per-dimension interpretations, written by an LLM. It can be Claude, **NVIDIA NIM**, OpenAI, Google Gemini, Groq, Mistral, DeepSeek, Together, OpenRouter, Fireworks, xAI, Perplexity, a self-hosted Ollama, or any OpenAI-compatible endpoint. Generations are cached by non-identifying keys, so most reports need zero or one API call. If the provider is unavailable, the pre-written text is used and the report never fails.

It runs as a complete platform. Admins sign in at `/admin`, create a personal link for each employee, track progress, and read reports; employees take the test through their link and never see results. It also includes SQLAlchemy persistence with responses encrypted at rest, text, JSON and PDF export, and analytics.

> **Before using scores for real decisions:** the item→dimension key (`data/question_bank.json`) and the Sten norms are **provisional**. Replace the key with a validated one, and calibrate norms on your own candidate population (`GET /api/norms/suggested`). Every report carries `"scoring_key"` and `"norms"` fields that show which you are using.

## Quick start

```bash
cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

python example_usage.py          # score the sample candidate, export txt/json/pdf to output/
pytest tests.py -q               # 54 tests; no API key or network needed (TEST_DATABASE_URL=postgresql://... runs them on Postgres)
python benchmark.py              # latency + cache hit rate on 1,000 simulated candidates
uvicorn api_server:app --reload  # http://localhost:8000/admin (build the web app first: npm run build in the repo root)
```

The first visit to `/admin` creates the admin account (see [INSTALLATION.md](docs/INSTALLATION.md)). To enable AI content, go to **Settings → AI provider**, choose a provider, paste its API key, click **Fetch models**, pick a model, and click **Save & test connection**. The key is tested before it's saved, stored encrypted, and never shown again. Then use **Generate AI analysis** on any report, or **Analyse cohort** on the dashboard. You can also configure a provider with environment variables (see CONFIGURATION.md). Without a provider, everything still works, and premium sections use the pre-written fallback.

## Files

| File | Purpose |
|---|---|
| `hybrid_assessment_engine.py` | `QuestionBank`, `ResponseValidator`, `HybridScoringEngine`, `LLMInterpretationCache`, `LLMInterpreter`, `HybridReportGenerator`, `STEN_TABLE`, `INTERPRETATIONS` |
| `database_models.py` | SQLAlchemy models (`TestTaker`, `Assessment`, `Response`, `Result`, `LLMCacheEntry`, `LLMSettings`, `AdminUser`, `AdminSession`, `Invitation`), response encryption, analytics queries |
| `api_server.py` | FastAPI app and REST endpoints |
| `llm_providers.py` | Provider adapters: Anthropic (SDK) plus one OpenAI-compatible adapter for NVIDIA NIM, OpenAI, Gemini, Groq and the rest |
| `exporters.py` | Text, JSON and PDF rendering |
| `config.py` | Environment-driven settings |
| `tests.py` | Unit and integration tests |
| `example_usage.py` | Worked end-to-end example |
| `benchmark.py` | Performance and cache-efficiency benchmark |
| `data/question_bank.json` | 175 items with their dimension and reverse-keying (generated by `data/build_question_bank.py`) |
| `data/sample_responses.json` | Sample input in the API format |
| `auth.py` | Admin accounts: password hashing, sessions, CSRF, login rate limiting |
| `manage.py` | `create-admin`, `reset-password`, `list-admins` |
